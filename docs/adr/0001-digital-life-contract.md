# 单 lineage 的有界数字生命目标

Status: accepted

Brain Memory 的下一阶段以“单一生命谱系、单一活动个体的数字生命原型”为开发目标：它在有限资源和受控环境中维持身份、求真、自治、成长、连贯与连接，并通过明确的生命周期状态持续、休眠、降级、恢复或终止。我们不把主观体验作为可由本项目证明的验收条件，也不把开放式繁殖作为本阶段目标；灾难恢复型 successor 是连续性机制，而不是常态繁殖。

选择有界单体而非无限复制或永久运行，是为了让生命性具有可重复的验收边界，同时保留后续研究 lineage 演化的空间。所有历史能力标签和产品发行号继续保持各自语义，不代替 lineage 或 generation。

## Consequences

- 同一 lineage 同时只有一个 active organism，历史 generation 只读封存。
- 生存以资源、时间、故障和身份不变量衡量，而不是以“永不停止”衡量。
- 进步、恢复、换代和繁殖成为不同领域概念，不能互相冒充。
