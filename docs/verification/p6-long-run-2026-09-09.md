- 工作目录：项目根目录（不记录本机绝对路径）。
- 工作分支：`codex/stability-continuity-baseline`。
- 目标：单一 lineage、同一时刻单一 active organism、可审计的生命周期/动机/评估/恢复/代际接替闭环。

- 活动树与候选树必须是专用运行时树；控制器拒绝包含 `.git`、`.hg`、`.svn`、`.venv`、

- 敏感路径扫描只检查名称和目录元数据（公共 `.env.example`/`.env.sample`/`.env.template`

## 交易恢复闸门

候选晋升采用外置、原子更新的交易清单，阶段必须按以下顺序推进：

`PREPARED → ACTIVE_MOVED → SWAPPED → COMMITTED`

回滚使用独立的 `ROLLBACK_STARTED → ROLLED_BACK` 阶段。进程在任一重命名之间退出时，新的控制器必须依据清单和目录实际形状恢复旧 active，或在证据不足时 fail-closed；不得丢弃唯一备份、重复晋升或无收据地宣称成功。`close()` 不代表放弃回滚，待处理备份只有在显式授权的 finalize/discard 操作中才能清理。

## 已确认的残余边界

- `PromotionController` 的文件锁和清单是合作进程间的协调机制，不是操作系统 ACL；需要阻断网络、任意宿主写入或恶意同进程候选时，必须由外部容器/job/supervisor 提供隔离。
- 生产候选链接入来源 attestor 时，必须绑定 append-only SQLite replay ledger；每个证明只保存
  opaque replay/proof hash 并以 `BEGIN IMMEDIATE` 原子消费。该账本故障会拒绝事件；它依赖同一
  持久数据库、受信时钟和宿主 ACL，也不会防御数据库文件整体回滚。表为保留一次性语义不自动
  删除历史行，长期归档/容量告警属于部署运维责任。
- `ResourceLedger` 是有界哈希证据缓存；到达容量时最后一个槽位记录一次容量隔离事件，之后
  只返回稳定的 `QUARANTINE` 决策并等待独立恢复，不会删除历史或把未记录的观测当作成功。
  因此长时部署仍须监控容量并在隔离后执行人工/外部验证。
- 评估收据的内容哈希保证完整性，不单独证明签发者身份；生产路径的 evaluator/attestor 秘密和运行权限必须由宿主隔离，`legacy` profile 仅用于明确的兼容/测试场景。
- SQLite 租约、原始数据库访问和显式 `now=` 测试时钟都依赖受信宿主；生产调用应省略测试时钟并使用文件/数据库 ACL。
- 心跳续租、外部线程序列化、宿主崩溃后的人工介入未在本轮作为真实生产环境证据验证；不得用静态代码检查替代这些运行证据。
- `PromotionController` 的低层 API 不自动绑定 `LifeKernel`/lineage；只有 `BrainStem` 的
  生命周期、稳态和宿主接线共同构成完整生命管道。直接使用低层 API 时，宿主必须自行
  维护 lineage 与 active 单实例约束。
- 默认宪法/生命周期/评估/权限路径是不可弱化的保护底线；`protected_files`/`protected_paths`
  只能增加项目路径。实际项目仍需核对 file-backed ledger 位于活动根目录之外。
- 重解析点/硬链接检查、原子重命名和 sidecar 文件锁属于静态或合作进程保护，无法单独
  覆盖恶意并发替换、Windows ACL/ADS、SMB/网络文件系统或外部进程权限；生产宿主应
  冻结候选树并补充 ACL、容器/job/supervisor 隔离。Windows 上 fixture 的 `chmod` 只读
  也是 best-effort，内容哈希才是本地完整性证据。
- `verify()` 逻辑上不修复目录，但 file-backed ledger 可能为跨进程读取创建或刷新 lock
  sidecar；需要绝对无写语义的审计环境应使用只读副本。
- 生产 coordinator 要求每个自定义 sink 返回内置布尔 `True`；`None`、非布尔 truthy 值和
  `False` 都会拒绝接替。不过 Python callable 本身仍无法证明它确实产生持久副作用。当前生产
  主路径由 `BrainStem` 的完整、带 `db_path` 的 `StateStore` 适配器接线并 fail-closed，
  更强的 `DurableSink` 能力证明留待后续兼容性设计。
- 本记录不宣称系统具有主观体验或意识；它只证明有界的连续性、求真/完整性、自治、成长和恢复机制在测试范围内成立。
