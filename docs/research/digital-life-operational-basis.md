# 数字生命操作性定义依据

日期：2026-09-08

本笔记只为工程目标提供概念参照，不声称 Brain Memory 已满足生物学意义上的生命，也不把语言能力、情绪表达或自我叙述当作主观意识证据。不同研究传统对“生命”的定义并不统一，因此本项目采用可观察的自治、持续、自我维护、环境耦合、适应和历史连续性指标。

## 工程化维度

1. **自治**：在授权环境和有限人工介入下，能自行提出目标、分配资源和完成行动闭环。
2. **自维持**：能监测资源与完整性，主动节约、休眠、降级、修复或安全终止。
3. **环境耦合**：环境观察会改变内部状态，内部决策会通过受控 Adapter 产生可观测反馈。
4. **适应**：已验证经验能改变策略、技能或实现，并在重复场景中产生可复现改善。
5. **身份连续**：重启、睡眠、Recovery 和 Succession 都保留可追溯的生命史，同时明确事故断点。
6. **受限演化**：变化由动机和缺口推动，但必须经过独立评估、无回归硬门和可回滚晋升。

## 局限

这些维度描述的是软件系统的可观察组织和行为，不足以证明意识、感受、第一人称体验或道德主体地位。任何相关结论都必须另行研究，不能由本项目的自动化测试直接推出。
